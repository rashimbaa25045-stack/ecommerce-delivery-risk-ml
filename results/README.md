# Results

This folder contains exported model-comparison tables and presentation-ready plots generated from the analysis.

## Main results

- Ridge RMSE: approximately 6.88 days
- Random Forest ROC-AUC: approximately 0.766
- Decision Tree late-delivery recall: approximately 62.9%
- K-Means: 4 seller clusters, silhouette approximately 0.493
- Dissatisfaction: 9.19% for on-time orders vs 53.98% for late orders
- Holt-Winters holdout RMSE: approximately 19,355 revenue units/day

See the root `README.md` and the executed-results notebook for interpretation.
